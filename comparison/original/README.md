# Original, for comparison and tuning

The clips here are footage of the original PS3 menu background, not part of this project's code:
the PS3 system menu (system software 4.93) running in the RPCS3 emulator, with the menu's icons,
text and clock hidden so that only the background shows. They may be watched beside this project's
renderer and used as references to tune it against, like the public recordings listed in
`docs/references/sources.md`. Nothing in this repository is taken from them.

All clips: theme colour Original, 1920 x 1080 (the console's own 1080p output), 60 fps, real
speed, H.264. "After start" is the console time from the start of the menu to the clip's first
frame.
