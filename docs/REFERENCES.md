# Public references

Public recordings of the original effect that renders were compared against,
side by side. Only genuine recordings of the original (on hardware or in an
emulator) are used; fan recreations are excluded. Nothing was downloaded from
the console's system software, and no recreation's code or project files were
consulted. On-screen menu icons, text, clocks and watermarks are ignored.
